# keyboardv1
For hack club stasis, I have to journal a lot, and when I journal, I'm locked in, I just keep on typing and typing until I realise that my hands ache like hell because of my uncomfortable keyboard. Because of this, I decided to make myself a customisable 65% keyboard that I can use for playing games (I can customise the keys and make different modes for what I'm doing), journal and all my other typing needs. I created a keyboard matrix for the schematic and placed all my keys into a specific format in the pcb along with making some stablisation holes for space bars and other keycaps. I also added some tuff af silkscreen to the PCB. For the case, I designed a simple, sleek case which surround the keyboard and has no lid. I made it simplistic but added some small design additions so the keyboard wouldn't get to boring. I also added a small slot to the case of my split keyboard which I can use to attach modules whihc I can design in the future. Overall I am really proud of what I made and can't wait to build it irl.
